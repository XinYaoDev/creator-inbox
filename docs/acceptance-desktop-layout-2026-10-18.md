# 桌面底部空白修复 — 2026-10-18

## 原因与修复

工作流末尾的读屏专用 `g-sr-only` 元素为绝对定位，但内容滚动区没有建立定位包含块，隐藏元素仍以末尾静态位置撑大了整个文档。修复为内容区建立包含块，并将读屏文字锚定在起点；没有删除无障碍文字，也没有用全局禁止滚动掩盖问题。

遵循桌面布局及无障碍设计检查：窗口负责固定导航和标题，内容区负责滚动，不裁掉底部功能，不损失读屏提示。

## 实测

- 1280 × 720 的真实 WebKit 页面：修复前文档高 1887、窗口高 720；修复后两者均为 720。
- 工作流内容区仍保留 1741 的内容高度。键盘定位最后一条执行记录后，内容区滚到 1201，而窗口滚动量仍为 0；底部执行记录在视口内。
- 已在用户打开的 Laike AI 桌面客户端载入，确认外层整页滚动条消失，画布及内部滚动保留。
- 前端生产构建成功，修复时现有 162 项测试全通过；另增布局定位回归测试，防止隐藏文字再次逃逸。
- 此项为布局修复，不代表后端内置、回滚及大文件同步功能已完成。
