微信客服不是员工的个人微信聊天，也不是企业微信客户联系。上述渠道的营销卡片和自动化工作流外发尚未开放；收到非文本消息会转本地人工，需到原平台查看。工作台的人工接管控制本地 AI，不等于已调用平台坐席分配接口。

## 操作与安全边界

接入中心按填写账号、检查连接、启用接待分三步。生成回调凭据、可管理客服账号自动选择、状态检查和复制按钮减少重复操作；凭据及回调未验证时不能进入启用步骤。旧版采集账号默认收起，账号数量显示为已添加，不再暗示已获得官方消息权限。

- 管理员配置，工作空间隔离；同一个平台账号不能跨空间重复绑定。
- Secret、回调凭据、原始回调事件以 AES GCM 加密存储。重开表单不返回密钥；使用现有完整备份包含的本机主密钥。
- 配置变更使用版本检查。更改身份须新建账号；更改密钥或回调地址会暂停接入并要求重新检查。
- 回调只接收安全模式加密消息，校验签名、时间与收件身份，限制体积和速率。消息先持久化再应答；拉取失败退避重试，超出次数保留待处理记录。
- 文本发送限制 2048 字节。当前仅实现用户消息触发的 48 小时和 5 条回复窗口，所有外发还受平台实际权限和会话状态约束。
- 发送幂等、会话串行限额。网络超时标记为结果未知，禁止自动重发或换请求标识绕过，管理员须在原平台核实并记录依据。
- 模型生成期间或访问凭据刷新期间停用接待，会阻止尚未提交的平台外发。已经提交给平台的请求无法在本地撤销。
- 本机独立回调入口默认关闭，只监听 127.0.0.1；不提供管理 API、页面或文件。尚未部署公网反向代理或隧道，不能将整个桌面工作台暴露到公网。

## 验收结果

全量项目测试 208 项通过；最后修改后的渠道专项测试 17 项通过。生产构建通过，存在原有较大前端包提示。

协议测试使用隔离数据库与受控平台响应，覆盖加密、验签、身份隔离、空页继续翻页、恢复游标、重复进线、退避、并发额度、过期窗口、异步回执、取消关注、非文本转人工、模型期间停用、刷新凭据期间停用、未知结果人工核实。它们不代表真实平台授权成功。

实际服务测试启动独立 Node 后端，以真实 HTTP 发送加密中文回调，验证持久化、重启恢复、重复消息、错误签名及桌面管理入口隔离。隔离数据库中的已验证账号是测试前置条件，不是微信真实授权。

浏览器实操完成新建隔离测试配置、检查向导、未验证禁止启用、回调入口开关和重新打开密钥不回显。1024 像素及 390 像素宽度下检查布局，390 像素视口没有页面横向溢出。

桌面实操通过维护面板创建完整备份、验证签名并安装更新；打开了新增接入中心与微信客服表单。实际启动本机回调入口后验证仅监听 127.0.0.1:18879，管理路径及无效账号回调返回 404，验收后关闭入口。未在正式桌面数据库保存虚构平台账号，未向任何外部顾客发送消息。

更新后的业务记录、模型设置校验与更新前一致。业务校验只规范化持续来源调度标记的 updated 时间，未忽略业务内容。安装时已有 3 条会话、3 条知识、3 条线索；这些是当前安装数据，不是此前超大规模隔离测试的数据集。

## 真实授权后的验收顺序

1. 管理员在客户端填写一个微信客服或认证公众号的凭据，配置可用公网 HTTPS 回调。凭据不发到聊天。
2. 检查 API 权限、账号管理范围、可信 IP，保存平台回调配置并验证。只开放专用回调入口。
3. 保持人工接待，从自己的顾客测试账号发送消息；检查正确账号与工作空间入线、中文和重复消息。
4. 在统一接待回复，在原平台确认收到；平台接受请求不能替代实际收到的验证。
5. 测试原平台人工回复、消息撤回、非文本、重复回调、重启、权限撤销、窗口过期和失败处理。所有测试限于用户指定的测试账号。
6. 真实人工收发通过后，明确启用 AI，验证知识引用、多轮上下文与人工接管；再按平台能力补媒体、卡片和工作流。
7. 小红书与抖音先取得属于本产品或经正式合作授权的应用能力和协议，再完成 OAuth 与消息适配。不能借用来鼓应用的授权冒充本产品授权。
